## 修了一个 bug

**中键拖动松手后，窗口又回到原来的位置。**

### 现象

用鼠标中键按住待办卡拖动，松手后（尤其鼠标一移开、卡片收起时），窗口会弹回拖动前的位置。看起来是「拖了等于没拖」。

### 根因

中键拖动走的是「页面算位移 + 主进程 `setPosition`」这条路（因为顶栏只有 22px，中键够不着系统原生拖动区）。而 Windows 上，程序化 `setPosition` **不会触发 `moved` 事件**——这个事件只在系统原生的标题栏拖动时才来。

而「记住位置」和「位置锚点更新」这两件事，之前都写在 `moved` 事件里。于是中键拖完，锚点没更新、存档也没写；松手后鼠标一移开、卡片收起时，主进程用**旧锚点**反推窗口位置，就把它拉回了原位。

左键抓顶栏是系统原生拖动，会正常触发 `moved`，所以左键一直没这个问题——这也是为什么之前没被发现。

### 修复

- 中键拖动过程中，每次移动都同步更新位置锚点；
- 松手时直接落盘位置，不再等那个根本不会来的 `moved` 事件。

### 验收

- 真机真按键（`SetCursorPos` + `mouse_event`，跟人手按住没区别）对比左键/中键，定位到根因；
- 新增两条回归：`verify-persist`（拖完读存档，x/y 精确 +70/+46）与 `verify-nobounce`（松手后移开鼠标，窗口不弹回）；
- 全量回归 239 条断言全过。
