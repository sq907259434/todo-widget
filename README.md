# 待办清单 · TodoCard

> 贴在 Windows 桌面上的待办小卡：平时只剩几条任务框，鼠标碰到才展开成完整卡片。
> 本项目原是「桌面卡片套件」（天气 + 待办合体，1.9.1 为最后合体版）里的待办卡片，现已拆分为独立应用，单独发布。

## 特性

- **平时只剩条目** —— 待办卡平时只显示待办本身：标题、历史/更多/关闭、输入框、底部统计全部收起，卡片真的变矮；鼠标移进卡片才展开，且展开时条目在屏幕上一动不动
- **连卡片底都没有** —— 收起时卡片背景、内高光、叠加色全部撤掉，窗口是真透明的，桌面上只剩几个圆角任务框；鼠标移进才长出卡片底色来托住顶栏和输入条
- **一条都没有时也是一行** —— 空列表不再是"还没有待办"的占位文案，而是把输入框本身摆成一条待办：`待办 + 写点什么 + ＋`，高度和一条待办完全一致，敲回车加第一条时窗口纹丝不动；**＋ 永远钉在最右端**
- **几条就多高** —— 窗口高度严格跟着条数走：1 条最矮，每多一条 +33px，删一条立刻缩回，不预留空位
- **打字完挪开就自动记下** —— 不用记得按回车：鼠标一离开卡片（0.3 秒内回来不算），输入框里的话就自己变成一条待办
- **标题旁的数字 = 还没办完的条数** —— 3 条里已完成 1 条就显示「待办 2」；全做完显示「全部完成」
- **双击就能改字** —— 写错了直接双击那条的文字，就地改；`Enter` 或点别处保存，`Esc` 反悔
- **拖窗口按顶栏** —— 顶栏就是这张卡的标题栏，按住它拖跟资源管理器一样；任务框不变抓手、不会抬起变形
- **拖动是自己实现的，不是系统标题栏拖动** —— 卡片贴进桌面层后是桌面窗口的子窗口，系统那套标题栏拖动在子窗口上不生效（按着拖会慢半拍甚至完全不动）。所以改成主进程每 8ms 读一次系统光标、直接挪窗口：跟手、无累积漂移。代价是失去 Windows 的 Aero Snap 贴边分屏（卡片也用不上）
- **左半边不展开** —— 光标停在卡片左侧一半（勾选圈那一带）时保持简洁，只有往右越过中线才展开整张卡；点「已完成」不用整张卡弹出来
- **右滑删除只看到条目** —— 一按下去就切成只剩任务框，松手复原（不管按之前卡片是不是展开的）
- **拖动时只剩任务框** —— 一开始挪，卡片底、顶栏、输入条、页脚就淡出，桌面上只剩那几个框。挪的时候要看的是"这几个框跟别的窗口齐不齐"，一块卡片底垫在下面反而看不准。位置一个像素都没动，松手就原样长回来
- **中键也能拖** —— 不想去找那条 22px 的顶栏就按中键：按住卡片**任意一处**都能拖（正在打字的输入框也算，只要不移动就是普通的中键粘贴，窗口不动）。桌面层里页面的中键事件不总是送得进来，所以主进程另外每 16ms 看一次系统按键状态兜底。顺手把系统那个"中键自动滚动"圆圈也吃掉了
- **鼠标在框里就不会自己收** —— 收起只看一件事：系统光标有没有真的离开窗口矩形。展开时窗口会向上长，这时候浏览器会自己误判一次"鼠标走了"，以前就被它带着缩回去；现在那声误报不算数
- **不会自己跳出来打扰你** —— 卡片被别的窗口挡住时，鼠标扫过它所在的区域也不会自己弹到最前（v1.0.3 起移除了这个行为）；想唤回见[下面](#卡片被挡住找不到了)
- **任何背景上都读得清** —— 卡片透明，但每个任务框/输入框自带一层深色玻璃，摆在白底的行情软件或 Word 前面也不会"看不见"
- **历史记录** —— 顶栏时钟图标进入历史视图，按今天/昨天/更早分组，看得到什么时候完成了什么、删掉了什么，误删可一键放回
- **不打扰** —— 默认不置顶、不占任务栏、不抢焦点，就安静待在桌面上
- **绿色免安装** —— 同时提供安装版（带开始菜单/桌面快捷方式）和单文件绿色版

## 快速上手（30 秒）

1. **双击运行**（绿色版直接双击 exe；安装版从「待办清单」快捷方式启动）—— 一张卡片出现在**屏幕右上角**
2. **鼠标碰上去**，卡片展开，露出标题栏和输入框
3. **在输入框打字，按 `Enter`**（或直接把鼠标挪开），一条待办就加上了
4. **做完一条**：点它左边的圆圈，文字划掉；想删就点右侧出现的垃圾桶，或按住那条**往右滑出卡**
5. **挪位置**：按住顶栏（「待办 2」那一行）拖；嫌顶栏窄就**按住中键**在卡片上任意处拖。松手自动记住，下次启动还在原地
6. 想让它一直待在最上层：右键卡片 → 勾「窗口置顶」；想开机自动出现：勾「开机自动启动」

就这么点事。更细的操作和原理往下看。

## 卡片被挡住/找不到了

卡片默认不置顶，被别的窗口盖住是正常的 —— **它不会自己弹出来打断你**（v1.0.3 起）。想把它叫回来：

- 右键桌面空白处 →「显示待办卡片」（需要先在卡片右键菜单里勾过一次「桌面右键菜单显示」；Windows 11 在「显示更多选项」里）
- 或者把压在它上面的窗口挪开/最小化

## 使用

平时只有条目（鼠标不在卡上，卡片背景本身也不画，桌面直接透出来）：

一条都没有时，整张卡就是那一行输入框：

![待办卡片 · 空态](docs/todo-empty.png)

鼠标移上去展开：

![待办卡片 · 展开](docs/todo.png)

| 操作 | 效果 |
| --- | --- |
| 鼠标移进卡片 | 整张卡展开：标题、历史/更多/关闭、输入框、底部统计出现（窗口向上长，条目不动）；**光标真的离开窗口**才收回，只剩条目 |
| 点历史/外观 | 标题栏右侧时钟图标 → 历史记录；页脚「← 返回待办」（整条页脚都能点）回到待办。**点桌面空白也会自动返回并收起** |
| **按住顶栏拖** | 顶栏就是标题栏：按住「待办 2」那一行拖，整张卡跟着走，松手自动记住位置 |
| **按住中键拖** | 卡片任意一处都行，正在打字的输入框也算（不移动就还是中键粘贴，窗口不动）：按住就能挪。**两种拖法都会在拖动期间把卡片底和顶栏收起来**，只剩任务框，方便看对齐 |
| 输入文字 + `Enter` | 添加一条 |
| **输入完直接把鼠标挪开** | 有内容就自动加进去（挪开 0.3 秒内又回来则不算，可以接着打） |
| **双击某条的文字** | 就地改成别的字：`Enter` 或点别处保存，`Esc` 反悔；清空后回车视为放弃，不会把条目删掉 |
| 点左边圆圈 | 标记完成：文字划掉、整条变浅，**位置不动**（不会跳到底部） |
| 再点一次圆圈 | 取消完成 |
| 鼠标移到某条上 | 右侧浮出垃圾桶，点它删除 |
| 按住条目往右滑 | 滑过约 1/3 卡宽松手即删除；不到阈值会自动弹回 |
| 点顶栏时钟图标 | 切到历史记录视图，再点一次切回 |
| 历史里悬停某条 | 右侧浮出「↺ 放回待办」 |
| 页脚「清空历史」 | 清掉全部历史（不影响待办本身） |
| 右键卡片 | 菜单：添加待办 / 历史记录 / 清除已完成 / 桌面右键菜单显示 / 开机自启动 / 窗口置顶 / 退出 |
| `Ctrl`+`N` | 光标跳到输入框 |

![拖动中只剩任务框](docs/todo-drag.png)

**拖动的时候只剩任务框**：一开始挪，卡片底、顶栏、输入条、页脚就淡出，桌面上只剩那几条框 —— 挪位置时看的是"这几个框跟别的窗口齐不齐"，一块卡片底垫在下面反而看不准。

只撤皮肤不撤布局：顶栏/输入条/页脚用 `opacity` 淡出而不是 `display:none`，条目位置一个像素都不动。窗口高度也不改 —— 拖动中改高度会让系统重算拖动锚点，窗口会突然跳一下，所以宁可让上沿那块空着。松手后 0.3 秒内没再动就原样长回来。

**卡片高度就等于内容**：1 条待办时最矮，收起态就是一条的高度，鼠标移上去才展开；**每多一条正好长 33px**，少一条就缩回去；最多长到屏幕可用高度的 72%（再多的条目在卡片内部滚动）。如果卡片贴着屏幕底部，长高时会向上伸展、底边固定；条目减少后自动缩回你原来摆的位置。

**删除和完成都会留痕**：历史记录保留最近 120 条，按「今天 / 昨天 / 具体日期」分组，标出完成时间。删错了可以放回待办（一律回到未完成状态，免得立刻被「清除已完成」清走）。

![历史记录](docs/todo-history.png)

数据存在渲染进程的 `localStorage` 里（待办 `todo_v1`、历史 `todo_hist_v1`），完全离线，不上传任何地方。

### 桌面右键菜单

在卡片上右键勾选「桌面右键菜单显示」后，**桌面空白处右键**会多出一项「显示待办卡片」，点一下就启动（已在运行则直接唤出，不会开第二个）。

- 只写 `HKCU\Software\Classes\DesktopBackground\Shell\TodoWidget`，不碰 HKLM、不需要管理员权限
- 注册表键名与天气卡片的 `WeatherWidget` 互不干扰，**两个应用都装也不冲突**
- 卸载安装版时自动清理这一项；取消勾选也会删掉
- Windows 11 的桌面右键是新版精简菜单，这一项在「显示更多选项」（或按 `Shift`+`F10`）里

### 关于"窗口置顶"

默认**不置顶**——卡片待在普通窗口层，被别的窗口挡住时会安静待在后面，**鼠标扫过也不会自己弹出来**（v1.0.3 起）。如果你希望它一直在最上层，右键菜单勾选「窗口置顶」即可。

**按 Win+D 显示桌面时，卡片不会消失**（v1.0.7 起）：显示桌面期间卡片临时浮到最上层（不这么干会被系统一起收走，且系统不给程序任何通知）；桌面一收回，卡片立刻沉回所有窗口下面——不会挡着你刚恢复的窗口等你去点它。

### 贴进桌面（和桌面图标同一层，v1.0.9 起，可选）

右键菜单勾选「**贴进桌面（和桌面图标同层）**」后，卡片会变成桌面窗口的子窗口，从此待遇和桌面快捷图标完全一样：**按 Win+D 完全不动**，也永远不会浮到别的窗口前面。想切回来再按一次 `Ctrl`+`Alt`+`1`（万一看不见窗口时，这个快捷键同样有效——它会改回普通窗口并自动重启）。

原理一句话：桌面图标其实不是窗口，它们住在桌面窗口 `Progman` 内部（`Progman → SHELLDLL_DefView → SysListView32`），而 Win+D 只收「顶层应用窗口」，从不碰这棵树。所以想同层，只能 `SetParent` 进去。

代价与注意：

- **磨砂材质不可用**（待办卡本来就是透明自绘，不受影响；天气卡在桌面层模式下会自动关掉系统磨砂）
- **两张卡都在桌面层时，鼠标指哪张、哪张就在前面**；移开不会沉下去（沉下去就等于掉进桌面图标层背后，看起来就是"卡片自己消失了"）
- **Explorer 重启会让卡片跟着消失**（父窗口被销毁，孩子一起没），重新双击快捷方式即可；程序每 3 秒会自检并重建父子关系
- 切换会**重启卡片一次**（约 1.5 秒），这是故意的：窗口层级在启动时一次做干净，比运行中反复挂/摘可靠
- **卡片不会再"吃掉"桌面图标**（v1.0.13 起）：桌面层里窗口比的是"父窗口壁纸"，透明像素透得出壁纸、透不出图标层，所以窗口形状改成跟视觉严丝合缝 —— 展开时是整张卡，收起/拖动时只剩待办那几条（`SetWindowRgn` 实时裁剪）。多出来的地方既不画也不收鼠标，图标原样露出、点得到
- **半透明处能看见桌面图标了**（v1.0.14 起）：真透明在桌面层里永远只透壁纸（把卡片挂到画图标的 `SysListView32` 下、以及 `SetWindowBand` 桌面档位两条路都实测过，都不行），所以改成"桌面快照"——用 `PrintWindow(Progman, PW_RENDERFULLCONTENT)` 抓一张壁纸+图标的整屏图，按窗口位置裁一块垫在卡片最底下。代价：快照是静态的，图标挪过/换过壁纸之后要点右键菜单里的「**刷新桌面背景**」

### 外观设置（透明度 / 磨砂，v1.0.14 起）

右键菜单 →「外观设置（透明度 / 磨砂）」，卡片里会出现两条滑杆，拖动即时生效：

| 滑杆 | 作用 | 说明 |
|---|---|---|
| 透明度 | 压在桌面背景上的那层底色有多浓 | 0% ≈ 几乎全透（只看得到图标轮廓），越高越接近实心卡片 |
| 磨砂 | 背景的模糊半径（0–20px） | 系统磨砂在桌面层里用不了，这里是**真的**去模糊那张桌面快照 |

设置存在 `widget-state.json` 的 `todo.look`，重启保留。

## 为什么不用系统磨砂（Acrylic）

它是透明窗口：系统 Acrylic 材质会铺满整个窗口矩形，页面再怎么透明也会被那层糊住，做不到"只剩几个任务框"。所以待办卡用 `transparent: true` + 页面自绘背景，展开时画渐变卡片、收起时什么都不画。

## 更新记录（1.0.17 → 1.0.26）

- **桌面快照不再周期性重抓**：原来每 20 秒无条件抓一次全屏快照（抓的时候卡片要隐藏 60~70ms），桌面上会看到卡片"闪一下"。改成按事件抓：换壁纸、改分辨率、在桌面上松开左键（60 秒最多一次），点应用窗口不抓
- **左键拖动不再漂移**：窗口是主进程跟着系统光标搬的，页面收不到 `mousemove`，原来那套靠 mousemove 的收尾逻辑会半途误判（拖到一半不跟手、位置还会跳）。改成主进程驱动开始/结束，拖动期间禁止改窗口高度
- **双击改字修好**：行内输入框以前没接输入桥（桌面层模式下打不进字），而且幽灵输入窗抢焦点会触发假 blur 把编辑框拆掉
- **写完点桌面能收回**：收桥时补放输入框焦点，`typing` 不再卡住
- **完全体拖动保持整张**：完全体模式下拖动不再抽皮肤
- **历史/外观有返回入口**：页脚「← 返回待办」；「清空历史」挪到列表末尾并两段确认（原来它就在页脚，容易被当"收起"点到）

## 已知限制

- 只在 Windows 上验证过
- 未做代码签名与自动更新
- 待办数据存在 `localStorage`，卸载时若勾选了删除应用数据会一并清空，建议重要事项别只记在这
- 卡片高度上限是屏幕可用高度的 72%，超过之后在卡片内部滚动（不无限长高，以免盖住整个桌面）
- **浅色壁纸下的可读性**：任务框/输入框自带深色玻璃底（`rgba(16,22,36,.55)` + 1px 亮边），白底前也能读。若整块桌面极亮且仍觉得偏弱，把 `todo.html` 里 `.item` / `.add input` 的背景透明度往上调（例如 `.72`）即可
